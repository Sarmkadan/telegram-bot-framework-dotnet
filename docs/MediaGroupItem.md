# MediaGroupItem

`MediaGroupItem` is an immutable record that describes one photo, video, audio, or document in an album sent with the Telegram `sendMediaGroup` method. It is the element type of the `IList<MediaGroupItem>` accepted by `ITelegramApiClient.SendMediaGroupAsync` and `MessageService.SendMediaGroupAsync`. The record is declared in `src/TelegramBotFramework/Integration/ITelegramApiClient.cs` together with the `MediaType` enum.

> **Note:** There is no `MediaGroupItemJsonExtensions` type in the current source tree. The file `Integration/MediaGroupItemJsonExtensions.cs` was removed in commit `eb337f1` ("remove junk JsonExtensions files generated by engines"), so this document covers only `MediaGroupItem` and `MediaType`. If JSON helpers for this type are needed again, they must be added as a new change.

## API

### Constructor

```csharp
public MediaGroupItem(MediaType Type, string FileIdOrUrl, string? Caption = null)
```

Creates a media item. `FileIdOrUrl` must be a Telegram `file_id` or a publicly reachable HTTP(S) URL. Throws `ArgumentNullException` if `FileIdOrUrl` is `null`, and `ArgumentException` if it is empty. Whitespace-only values are accepted by the constructor but rejected later by the API client. `Caption` is optional and is omitted from the request when `null`.

### Type

```csharp
public MediaType Type { get; init; }
```

The kind of media: `Photo`, `Video`, `Audio`, or `Document`. The API client maps it to the Telegram `type` field.

### FileIdOrUrl

```csharp
public string FileIdOrUrl { get; init; }
```

The media source sent as the `media` field. Either a `file_id` previously returned by Telegram or a URL that Telegram can fetch.

### Caption

```csharp
public string? Caption { get; init; }
```

Optional caption for this item. Each item may carry its own caption.

### Deconstruct

```csharp
public void Deconstruct(out MediaType Type, out string FileIdOrUrl, out string? Caption)
```

Supports positional deconstruction, for example `var (type, source, caption) = item;`.

### MediaType

```csharp
public enum MediaType
{
    Photo,
    Video,
    Audio,
    Document
}
```

## Constraints

A media group must contain between `MinMediaGroupItems` (2) and `MaxMediaGroupItems` (10) items. The Telegram API client enforces this in `SendMediaGroupAsync` and throws `ArgumentException` otherwise. `MessageService.SendMediaGroupAsync` checks the same bounds before calling the client. The bounds are defined in `TelegramApiClientConstants` and `MessageServiceConstants`. Every item must have a non-whitespace `FileIdOrUrl`.

## Usage

```csharp
using TelegramBotFramework.Integration;

var items = new List<MediaGroupItem>
{
    new(MediaType.Photo, "https://example.com/images/first.jpg", "Front view"),
    new(MediaType.Photo, "AgACAgIAAxkBAAIB...file_id", "Back view"),
    new(MediaType.Document, "https://example.com/files/spec.pdf")
};

ApiResult<IList<int>> result = await apiClient.SendMediaGroupAsync(chatId, items, cancellationToken)
    .ConfigureAwait(false);
```

Positional deconstruction:

```csharp
foreach (var item in items)
{
    var (type, source, caption) = item;
    Console.WriteLine($"{type}: {source} ({caption ?? "no caption"})");
}
```

Non-destructive changes use `with`, because the properties are `init`-only:

```csharp
var withoutCaption = items[0] with { Caption = null };
```
