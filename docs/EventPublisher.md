# EventPublisher

The `EventPublisher` class serves as a centralized event dispatch mechanism within the `telegram-bot-framework-dotnet` project. It enables the publication of various Telegram bot-related events, such as message receptions, command executions, and bot state changes, to registered event handlers. This facilitates decoupled communication between components and supports logging, monitoring, and other cross-cutting concerns.
