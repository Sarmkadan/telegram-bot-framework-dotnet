# ReplyKeyboardButton

`ReplyKeyboardButton` is a mutable, sealed class that describes one button inside a reply keyboard (`ReplyKeyboardMarkup`). It implements `IReplyKeyboardButton` and lives in the `TelegramBotFramework.Keyboard` namespace, declared in `src/TelegramBotFramework/Keyboard/ReplyKeyboardButton.cs`.

Buttons are normally not created by hand. `ReplyKeyboardBuilder` creates them internally, and the `Action<ReplyKeyboardButton>` overloads of `AddButton` and `AddRow` let you configure each one. When `Build()` runs, the builder converts every `ReplyKeyboardButton` into a Telegram.Bot `KeyboardButton`, copying `Text`, `RequestContact`, and `RequestLocation`.

> **Note:** There is no `ReplyKeyboardButtonJsonExtensions` type in the current source tree. The file `Keyboard/ReplyKeyboardButtonJsonExtensions.cs` was removed in commit `eb337f1` ("fix: remove junk JsonExtensions files generated by engines"). Its `ToJson`, `FromJson`, and `TryFromJson` helpers are therefore not available. If JSON helpers are needed again, add them as a new change.

## API

### Interface

```csharp
public interface IReplyKeyboardButton
{
    string Text { get; }
    bool RequestContact { get; set; }
    bool RequestLocation { get; set; }
}
```

`IReplyKeyboardButton` is declared in `Keyboard/IReplyKeyboardButton.cs`. `ReplyKeyboardButton` is its only implementation in the framework.

### Class

```csharp
public sealed class ReplyKeyboardButton : IReplyKeyboardButton
```

### Text

```csharp
public string Text { get; init; } = string.Empty;
```

The label shown to the user on the button. It is set with an object initializer and cannot be changed after construction. The default is an empty string.

### RequestContact

```csharp
public bool RequestContact { get; set; }
```

When `true`, pressing the button asks Telegram to prompt the user to share their phone contact. The default is `false`.

### RequestLocation

```csharp
public bool RequestLocation { get; set; }
```

When `true`, pressing the button asks Telegram to prompt the user to share their current location. The default is `false`.

### ToString

```csharp
public override string ToString()
```

Returns a diagnostic string in the form `ReplyKeyboardButton { RequestContact = ..., RequestLocation = ... }`. The `Text` value is not included.

## Behavior

- `Text` is immutable after construction. `RequestContact` and `RequestLocation` are mutable.
- The class performs no validation. Empty or whitespace `Text` is accepted here. Any limits are enforced by `ReplyKeyboardBuilder` or by the Telegram API.
- Telegram's `request_contact` and `request_location` options are only honored in private chats.
- Equality is reference equality, since the class does not override `Equals`.

## Usage

Configure buttons through the builder, which is the usual path:

```csharp
using Telegram.Bot.Types.ReplyMarkups;
using TelegramBotFramework.Keyboard;

ReplyKeyboardMarkup keyboard = ReplyKeyboardBuilder.Create(maxButtonsPerRow: 2)
    .AddButton("Share phone", button => button.RequestContact = true)
    .AddButton("Share location", button => button.RequestLocation = true)
    .NewRow()
    .AddButton("Cancel")
    .OneTime()
    .Build();
```

Create a button directly, for example in code that builds a `ReplyKeyboardMarkup` yourself:

```csharp
var contactButton = new ReplyKeyboardButton
{
    Text = "Share my contact",
    RequestContact = true
};

Console.WriteLine(contactButton); // ReplyKeyboardButton { RequestContact = True, RequestLocation = False }
```

Use the extension helpers for the common cases:

```csharp
ReplyKeyboardMarkup keyboard = ReplyKeyboardBuilder.Create()
    .AddContactButton("Share phone")
    .AddLocationButton("Share location")
    .Build();
```
