# Message

The `Message` class serves as the core data transfer object representing an incoming or outgoing communication within the `telegram-bot-framework-dotnet` ecosystem. It encapsulates essential metadata such as sender identity, chat context, content payload, and processing state, while providing built-in mechanisms for status management, metadata extension, and attachment handling. This type acts as the primary unit of work for message handlers, tracking lifecycle events from creation through processing completion or failure.

## API

### Properties

#### `MessageId`
```csharp
public long MessageId { get; set; }
```
Gets or sets the unique identifier for this specific message within the chat context. This value is typically provided by the Telegram API and remains immutable for a given message instance once assigned.

#### `UserId`
```csharp
public long UserId { get; set; }
```
Gets or sets the unique identifier of the user who sent the message. In the context of outgoing messages generated by the bot, this may represent the target recipient or the bot's own user ID depending on the instantiation context.

#### `ChatId`
```csharp
public long ChatId { get; set; }
```
Gets or sets the unique identifier of the chat where the message originated or is destined. This distinguishes between private chats, groups, and channels.

#### `Content`
```csharp
public string Content { get; set; }
```
Gets or sets the textual body of the message. For non-text messages (e.g., pure media), this property may contain a caption or remain empty depending on the `MessageType`.

#### `Type`
```csharp
public MessageType Type { get; set; }
```
Gets or sets the enumeration value defining the category of the message (e.g., Text, Photo, Document, Command). This determines how the `Content` and `AttachmentUrls` should be interpreted.

#### `Status`
```csharp
public MessageStatus Status { get; set; }
```
Gets or sets the current processing state of the message (e.g., Pending, Processed, Failed). This property is updated via the `MarkAsProcessed` and `MarkAsFailed` methods to ensure consistent state transitions.

#### `CreatedAt`
```csharp
public DateTime CreatedAt { get; set; }
```
Gets or sets the UTC timestamp indicating when the message entity was created or received by the framework.

#### `ProcessedAt`
```csharp
public DateTime? ProcessedAt { get; set; }
```
Gets or sets the UTC timestamp when the message processing was completed. This value is `null` if the message is still pending or if processing has not yet been attempted.

#### `CommandName`
```csharp
public string? CommandName { get; set; }
```
Gets or sets the name of the command if the `Type` is identified as a command (e.g., "start", "help"). This is `null` for non-command messages.

#### `Metadata`
```csharp
public Dictionary<string, object>? Metadata { get; set; }
```
Gets or sets a dictionary containing custom key-value pairs associated with the message. This allows handlers to attach transient data without subclassing. It is `null` if no metadata has been assigned.

#### `AttachmentUrls`
```csharp
public List<string>? AttachmentUrls { get; set; }
```
Gets or sets a list of URLs pointing to media attachments (images, files, etc.) associated with the message. This is `null` if the message contains no attachments.

#### `IsEdited`
```csharp
public bool IsEdited { get; set; }
```
Gets or sets a flag indicating whether the original message has been edited by the user after being sent.

#### `ReplyToMessageId`
```csharp
public long? ReplyToMessageId { get; set; }
```
Gets or sets the `MessageId` of the message this instance is replying to. This is `null` if the message is not a reply.

#### `ForwardedFromUserId`
```csharp
public int? ForwardedFromUserId { get; set; }
```
Gets or sets the user ID of the original sender if this message was forwarded. This is `null` if the message is not forwarded. Note the type difference (`int?`) compared to other ID fields (`long`).

### Methods

#### `MarkAsProcessed`
```csharp
public void MarkAsProcessed()
```
Updates the `Status` property to indicate successful completion and sets the `ProcessedAt` timestamp to the current UTC time.
*   **Throws**: No specific exceptions documented; ensures internal state consistency.

#### `MarkAsFailed`
```csharp
public void MarkAsFailed()
```
Updates the `Status` property to indicate a processing failure. It does not automatically set `ProcessedAt`, allowing differentiation between completed and failed states based on implementation specifics, though typically implies termination of the workflow.
*   **Throws**: No specific exceptions documented.

#### `GetProcessingDurationMs`
```csharp
public long GetProcessingDurationMs()
```
Calculates and returns the elapsed time in milliseconds between `CreatedAt` and `ProcessedAt`.
*   **Returns**: A `long` representing the duration in milliseconds.
*   **Throws**: May throw an exception if `ProcessedAt` is `null`, as duration cannot be calculated for unprocessed messages.

#### `SetMetadata`
```csharp
public void SetMetadata(string key, object value)
```
Assigns a value to a specific key in the `Metadata` dictionary. If the `Metadata` dictionary is currently `null`, this method initializes it before adding the entry.
*   **Parameters**:
    *   `key`: The string identifier for the metadata entry.
    *   `value`: The object value to store.
*   **Throws**: `ArgumentNullException` if `key` is null.

#### `GetMetadata`
```csharp
public object? GetMetadata(string key)
```
Retrieves a value from the `Metadata` dictionary by key.
*   **Parameters**:
    *   `key`: The string identifier for the metadata entry.
*   **Returns**: The associated `object` if found; otherwise, `null`.
*   **Throws**: No exceptions thrown if the key is missing; returns `null` safely.

#### `AddAttachment`
```csharp
public void AddAttachment(string url)
```
Appends a URL to the `AttachmentUrls` list. If the list is currently `null`, this method initializes it before adding the URL.
*   **Parameters**:
    *   `url`: The string URL of the attachment.
*   **Throws**: `ArgumentNullException` if `url` is null.

## Usage

### Example 1: Processing a Command with Metadata
This example demonstrates inspecting a message, validating it as a command, attaching custom processing metadata, and updating its status upon completion.

```csharp
public async Task HandleMessageAsync(Message message)
{
    if (message.Type != MessageType.Command || string.IsNullOrEmpty(message.CommandName))
    {
        return;
    }

    // Attach custom tracking metadata
    message.SetMetadata("HandlerVersion", "1.2.0");
    message.SetMetadata("ReceivedTick", Environment.TickCount64);

    try
    {
        // Simulate business logic based on command
        if (message.CommandName == "start")
        {
            // Process start logic
        }

        // Mark success
        message.MarkAsProcessed();
    }
    catch (Exception ex)
    {
        // Log error and mark failure
        message.SetMetadata("ErrorReason", ex.Message);
        message.MarkAsFailed();
    }
}
```

### Example 2: Handling Media Attachments and Replies
This example illustrates checking for attachments, verifying if the message is a reply, and calculating processing duration after the fact.

```csharp
public void AnalyzeMessageContext(Message message)
{
    // Handle attachments safely
    if (message.AttachmentUrls != null && message.AttachmentUrls.Count > 0)
    {
        foreach (var url in message.AttachmentUrls)
        {
            Console.WriteLine($"Processing attachment: {url}");
        }
    }
    else if (message.Type == MessageType.Photo)
    {
        // Fallback if type indicates media but list wasn't populated
        message.AddAttachment("https://placeholder.com/missing-media.jpg");
    }

    // Check conversation context
    if (message.ReplyToMessageId.HasValue)
    {
        Console.WriteLine($"Reply to message ID: {message.ReplyToMessageId.Value}");
    }

    if (message.ForwardedFromUserId.HasValue)
    {
        Console.WriteLine($"Forwarded from user ID: {message.ForwardedFromUserId.Value}");
    }

    // Calculate duration if processed
    if (message.Status == MessageStatus.Processed)
    {
        var duration = message.GetProcessingDurationMs();
        Console.WriteLine($"Processing took {duration}ms");
    }
}
```

## Notes

*   **Thread Safety**: The `Message` class is not inherently thread-safe. Properties such as `Status`, `Metadata`, and `AttachmentUrls` are mutable reference types. If a single `Message` instance is accessed across multiple threads (e.g., a handler reading metadata while another thread updates status), external synchronization (locks) is required.
*   **Null Handling**: Collections (`Metadata`, `AttachmentUrls`) are initialized lazily. Accessing these properties directly without checking for `null` may result in `NullReferenceException`. Always use `SetMetadata` and `AddAttachment` to ensure proper initialization, or check for `null` before iterating.
*   **Duration Calculation**: Calling `GetProcessingDurationMs()` on a message where `ProcessedAt` is `null` (i.e., status is not `Processed`) will likely result in an invalid calculation or runtime exception depending on the internal implementation of the subtraction logic. Ensure `Status` is verified before calling this method.
*   **ID Type Consistency**: Most identifier properties (`MessageId`, `UserId`, `ChatId`) are defined as `long`, whereas `ForwardedFromUserId` is defined as `int?`. Care must be taken when comparing these IDs or storing them in unified data structures to avoid truncation or casting errors.
*   **State Transitions**: The `MarkAsProcessed` and `MarkAsFailed` methods are intended to be the exclusive ways to modify the `Status` and `ProcessedAt` fields. Directly setting `Status` manually may lead to inconsistent states where `ProcessedAt` does not reflect the actual completion time.
